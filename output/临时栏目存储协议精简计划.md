# 临时栏目空占位与 Agent 读取方案

> 状态：已选择“约束文件 + 书签研究派生索引”方案。本文记录实际实施边界，不是 BCS 历史数据清洗或运行时迁移计划。

## 结论

临时栏目源 JSON 保持现有格式和历史数据。folder 可能带 `url: ""`，bookmark 可能带 `children: []`；这些字段属于当前序列化形状，判型以显式 `type` 为准。

Agent 不需要因为这两个空占位而怀疑数据损坏，也不需要把它们当作编辑目标。处理临时条目时：

- folder 依据 `type` 和 `children` 识别，保留有效子树；不把空 `url` 当网址。
- bookmark 依据 `type` 和 `url` 识别；不把空 `children` 当文件夹。
- 创建、增加、删除、修改、移动条目时，按任务需要处理有效的 `children`、`url`、ID、`sectionId` 和元数据；不为了占位字段单独改写源文件。
- `.canvas` 的 `file`、`group`、`text` 节点属于画布拓扑，不套用临时 item 的 folder/bookmark 规则。
- folder 的空 `children: []` 是有效的空文件夹状态，不能删除。

## 模板文件的职责

中英文 AGENTS 模板是直接交给模型阅读的自包含约束文件。模板只说明模型如何判断、读取和修改数据，不引用外部计划书章节，也不把插件 API 细节塞进模板。

模板必须包含这些规则：

1. 握手阶段只盘点宿主能力：插件、MCP/API、CLI、搜索、Git、文件和代码工具。
2. 核心红线禁止把整包、大栏目或大 JSON 全文倾倒进模型上下文；先用工具按目标节点、祖先、后代、路径和画布关系取片段。
3. 有插件时优先使用插件的索引和查询能力；无插件时用本地 JSON 工具按 ID 遍历，不靠标题或字段存在与否猜类型。
4. 查询结果是定位和理解用的投影，不能直接覆盖回源文件；写入前回读原节点，保留未修改字段和未知属性。
5. 临时栏目普通链式和特殊临时两类示例都说明 `type`、空占位和空文件夹的含义。

模板中不放 `get_context`、`search_bookmarks` 的完整调用模板；插件的接口说明和使用案例放在插件自己的 Skill/reference 文档中。

## 书签研究插件的职责

插件只建立包外派生索引，源 JSON 和完整文件快照仍是事实来源。索引构建不改写用户包，也不执行一次性清洗。

插件的临时条目投影规则：

- 定点搜索或上下文读取 folder 时，保留 `raw_json.children`，省略 folder 的空 `url`。
- 定点搜索或上下文读取 bookmark 时，省略空 `raw_json.children`，保留有效 `url`。
- `type`、`parent_id`、祖先链、路径、位置、标签和笔记继续保留。
- 全量 `inventory` 使用扁平条目行表达树：保留父 ID、路径和顺序，不在每个祖先行重复嵌套完整子树。
- compact 输出可以继续删除重复字段，但不能破坏树关系和定位信息。
- 非空冲突字段、缺失 type 或非法结构必须回到源节点核对，不通过精简投影掩盖异常。

插件提供按 source、section、item、folder 和分页范围读取的能力。模型只接收完成当前任务所需的页面，不能把一次小范围查询当成完整包扫描。

## 不实施的内容

本轮不执行以下工作：

- 不修改 BCS 存储协议、runtime 恢复逻辑或普通保存逻辑。
- 不对历史 section、自动备份槽或剪贴板历史做一次性清洗。
- 不改写备份、导入、导出、GitHub push/pull、JSON/HTML/ZIP 或跨类型转换的源数据。
- 不逐一改造旧版应用中的所有 serializer、clone、paste、drag/drop 和构造器。
- 不把模板或插件索引投影当作新的源文件格式，也不据此迁移旧用户数据。

这些路径继续按现有应用协议工作；本轮只保证模型读取时按类型理解，插件返回的派生结果尽量减少无意义空值。

## 验收依据

- 中英文模板不依赖外部章节编号，模型单独读取整个文件即可执行核心约束。
- 模板明确区分源文件字段与索引投影，不要求模型为了读取而清洗源文件。
- 插件测试覆盖 folder 子树保留、bookmark 空 `children` 省略、folder 空 `url` 省略、源包不变和树路径保留。
- 实际画布包可建立索引，并能按 item 或 folder 返回有限范围的树状上下文。
- 当前安装中的旧插件不会自动更新；源码验证通过不等于用户应用已经安装新版本。发布或重新安装插件后才进行运行环境验收。
