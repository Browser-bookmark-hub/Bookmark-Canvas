快捷键

Ctrl 键操作
Ctrl + 左键（按住） 拖动画布 或 栏目卡片
Ctrl + 滚轮 或 双指滑动 缩放
Ctrl + 右键（单击） 更改栏目卡片的大小
空格键操作
空格 + 左键（按住） 拖动全局画布
触控板操作
双指捏合 缩放画布
Ctrl + 双指滑动 缩放（兼容侧边栏）
双指滑动 拖动画布
批量选择
Shift | Option/Alt + 左键（单击） 批量/单个选中书签
左键框选
左键拖动（画布空白处） 多选元素并形成临时组，支持整组拖动、批量修改颜色/置顶/删除或转换为卡片组
元素右键
可右键元素 永久栏目及其副本、临时栏目、空白栏目、连接线、卡片组、左键框选的临时组、画布空白处
常用操作 全屏、定位、置顶、颜色、重命名、删除、复制源码、导出当前
