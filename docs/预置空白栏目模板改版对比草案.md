## 这版的修改原则

这次不重写原来的三张卡片。原来的文案已经比较像“首次打开时的轻量提示”，不应该改成完整说明书。更合适的做法是：

- 原文不删。
- 标题不大改。
- 原有段落顺序不动。
- 只在相关位置追加新功能点。
- 追加内容围绕两个 commit 已经落地的能力：Markdown/HTML 格式、说明框编辑、全屏/定位、卡片组/嵌套组、组导出、AI 指南文件。

## 落地时建议

- 这版是“原文 + 增补”，更适合直接落到 `createInitialDemoTemplate()`。
- 中文和英文的 `text`、`markdownSource` 继续保持同值。
- `html` 继续使用 `__renderMarkdownSourceToCanvasHtml(...)` 从 Markdown 渲染。
- 第一张和第三张内容变长，建议只小幅增加高度：第一张 `480 -> 560`，第三张 `420 -> 520`；第二张 `400 -> 500`。
- 如果想更保守，也可以只采用每张卡片新增的最后一个小节，不改卡片尺寸。
